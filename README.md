# Retail Demand Forecasting with Uncertainty and a Decision Layer

## Problem
Retail chains lose money in two opposite ways: stockouts, where empty shelves
mean lost sales and dissatisfied customers, and overstocking, where excess
inventory ties up capital and risks waste. Both stem from the same root
problem -- store managers must decide how much of each product to order
before actual demand is known. This project builds an end-to-end system that
forecasts daily store-level demand using historical sales, promotions, and
calendar data; quantifies the uncertainty in each forecast rather than
reporting a single number; and uses that uncertainty, combined with the
relative cost of running out versus overstocking, to recommend an order
quantity that minimizes expected cost. The result is deployed as a live web
application, so the forecast, its reliability, and its business impact can
all be inspected interactively rather than left in a notebook.
